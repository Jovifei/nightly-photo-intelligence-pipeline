# 研究目录

本目录回答“尽量参考现有 GitHub 工程”但不盲目复制的问题。

- `source_register.md`：官方/一手来源；
- `github_reference_projects.md`：复用的工程模式；
- `technology_decision_matrix.md`：采用/延后/拒绝；
- `model_candidate_register.md`：候选而非授权；
- `benchmark_protocol.md`：如何在 12GB 机器上作决定；
- `license_review_checklist.md`：代码、权重、数据分离审查；
- `unresolved_research_questions.md`：必须由实测/Owner 决定的问题。

研究日期是交付包生成日期。任何进入生产的依赖和模型都要在采用时重新核验。
