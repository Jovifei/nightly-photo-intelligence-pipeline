# 许可审查清单

- [ ] 官方来源；
- [ ] exact commit/revision；
- [ ] 代码 license 文件；
- [ ] checkpoint/weight license；
- [ ] 模型卡；
- [ ] 训练数据说明；
- [ ] 商业使用限制；
- [ ] 再分发限制；
- [ ] 归属/NOTICE；
- [ ] 专利条款；
- [ ] 量化/转换是否改变来源；
- [ ] 下载文件 SHA-256；
- [ ] Docker 基础镜像许可；
- [ ] Python 依赖许可；
- [ ] 输出是否可进入私有 App Bundle；
- [ ] 数据不得用于训练的 Owner 限制；
- [ ] Reviewer 结论；
- [ ] Owner 批准。

结论枚举：

```text
APPROVED_FOR_BENCHMARK_ONLY
APPROVED_FOR_LOCAL_PRODUCTION
REJECTED
NEEDS_LEGAL_REVIEW
UNKNOWN
```
