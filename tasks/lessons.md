# Lessons

## 2026-07-18 — Scope correction

- When the Owner explicitly narrows the active task back to the nightly photo
  pipeline, stop all adjacent-project work immediately and re-anchor execution
  to the current G1 contract, snapshot, manifest, and approval chain.

## 2026-07-15 — G1 Reviewer remediation

- A green synthetic suite does not prove the Owner's full contract. Audit each normative sentence
  against both production code and a direct test before marking remediation complete.
- Retry ceilings belong to a versioned policy loaded by the state store. Never let callers supply
  an arbitrary `max_attempts` that can silently bypass the configured retry limit.
- A test name is not evidence. Explicitly exercise every claimed terminal state, including both
  `SUCCEEDED` and `FAILED` heartbeat rejection.
- Keep archival handoff verification, plain unconfigured CLI preflight, legal synthetic preflight,
  and formally configured Owner preflight as separate results with their actual exit codes.
- Never carry historical real-photo evidence forward as post-remediation proof. Until the OS-level
  read-only gate passes, manifest metadata and non-mutating capability checks are the only permitted
  source-adjacent operations.
