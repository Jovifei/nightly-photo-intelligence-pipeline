# 业主更正：照片指导目标（2026-10-04）

这是长期有效的要求。以后做这个项目，按这里写，不要跑偏。

## 最终目标

做一款用来拍照的手机应用。

本流水线研究好看的参考照片，并说明每一张为什么好看。产出的是拍摄时能用的方向，不是统计报表。

## 每张照片要分析什么

- 构图和画面布局
- 光线：光从哪里来，落在哪里
- 身体姿态，以及四肢怎样配合
- 眼睛看向哪里
- 服装风格
- 其他让这张照片成立的因素

## 姿态怎么交付

姿态结果不是人数。

它是一段摄影师可以口头说出来的话，让客户或模特能照着把这个姿势做出来。

## 不作为主要结果

下面这些可以留在内部当信号，但不是要交给人用的产品结果：

- 数有几个人
- 平均姿态分数
- 遮罩占比

- `nightly-photo-intelligence-pipeline` 产出上面这些拍摄方向知识。
- 手机应用在 `E:\project\ai-photography-director-app`。它以后应在拍摄现场把这些知识说出来。
