# 范围与非目标

## 产品范围

- 本地收藏导入与指纹；
- 重复/不支持/需复核分类；
- 离线视觉分析；
- 分层知识结构；
- 人工审核；
- App Bundle 导出；
- 状态恢复、报告和审计；
- 单机 GPU 资源管理。

## 第一版非目标

- iOS 实时相机和 UI；
- 云端 API；
- 多用户权限；
- SaaS；
- 公共图库；
- 自动版权判断；
- 基础模型训练；
- 大规模微调；
- 分布式队列；
- Kubernetes、Kafka、分布式 Celery；
- 公共云数据库；
- 自动发布 App；
- OpenClaw 自主逐图决策；
- 用 500–600 张图宣称训练出通用摄影模型。

## N0 非目标

N0 不做任何真实视觉模型能力，不做 20 张校准，不生成生产 Review Card，不实现 Bundle release，不跑 Docker GPU 容器，不修系统环境。

## Scope creep 判断

以下都视为扩大 Scope，需要 Owner 批准：

- “顺便”下载一个小权重；
- 使用真实照片验证 Hash；
- 添加云端 fallback；
- 创建远程 GitHub 仓库；
- 引入工作流平台；
- 在主 App 中加入读取代码；
- 将 SQLite 换成服务型数据库；
- 把三张 fixture 换成任意本地图片。
