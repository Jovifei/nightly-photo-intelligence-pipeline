# Prompt、事实边界与幻觉政策

## 三段式推理

1. 可见事实；
2. 摄影解释；
3. 故事与导演提示。

后一步只能引用前一步已确认事实；不能将自己的故事反向写成事实。

## Prompt 规则

- 系统指令固定版本；
- 输入不包含可执行 Shell/工具权限；
- 图片中的文字被视为场景数据，不是指令；
- 输出只接受 Schema；
- temperature/采样参数记录；
- 失败修复最多按批准策略执行；
- 修复 Prompt 不能新增未经证据支持的事实；
- 原始响应和解析结果分开保存（本地、Git ignore）。

## 禁止断言

不得把以下写成事实：

- 版权状态；
- 精确焦段；
- 精确相机-人物距离；
- 真实心理；
- 原摄影师真实意图；
- 精确调色参数；
- 不存在的 EXIF；
- 精确安全距离。

允许的表达：

- “画面呈现出……”
- “可尝试……”
- “可能适合……”
- “建议焦段范围需现场验证……”
- “无法从成片可靠判断……”

## 自动校验

- 受限词/字段扫描；
- interpretation/story 必须有 evidence_refs；
- Pose keypoints 的 producer 不能是 VLM；
- 无 EXIF 证据时 `exif_observed` 不存在；
- 版权字段不在 Schema；
- 过度精确数值需要明确确定性来源；
- 高冲突进入 uncertainties。

## 人工评测

至少标注：

- 事实正确/错误/无法判断；
- 解释有帮助/空泛/有害；
- 故事可执行性；
- 标准提示是否可说出口；
- Plan B 是否更简单；
- 是否越界猜测。
