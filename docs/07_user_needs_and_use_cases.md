# 用户需求与用例

## UC-01 安全登记收藏

Owner 指定一个只读目录和批准 manifest。系统登记支持格式，计算 Hash，识别重复，不改原图。失败项有原因。

## UC-02 早晨查看处理情况

Owner 使用 `npi status` 和 `npi report --latest` 查看总量、状态、失败、复核、耗时、显存、模型/Prompt/Schema 版本。

## UC-03 查看单图审核卡片

卡片并排展示缩略图、骨架/轮廓、可见事实、摄影解释、三类故事、导演提示、不确定性和来源。Owner 可批准、拒绝或修正。

## UC-04 按场景检索

例如“窗边、单人、半身、清冷、手靠脸、动作简单”，返回已审核条目。检索不在 N0。

## UC-05 现场 Plan B

App 从 Bundle 中读取同一条目的标准动作、戏感和更简单 Plan B。App 不需要 Pipeline 在线。

## UC-06 中断恢复

第 437 张出错或系统重启后，系统只继续未完成/可重试阶段，并验证已有产物 Hash。

## UC-07 模型升级重跑

新模型或 Prompt 不能覆盖旧结果。以新 run/version 生成候选，经比较和审核后才进入新 release。

## 反用例

- 用一段自由 VLM 文本当作全部知识；
- 让 OpenClaw逐图决定 Shell；
- 从成片断言真实焦段、心理和版权；
- 直接把收藏目录同步到 App；
- 无审核自动导出；
- 因一次 OOM 删除已有产物。
