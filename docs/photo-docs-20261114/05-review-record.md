## 2. Muse 调研（2026-11-13/14）

### 2.1 技术路线调研

- 范围：姿势估计（RTMPose/RTMW、MediaPipe、Keypoint R-CNN）、深度（DA3）、VLM（Qwen3-VL）、视线（Face Mesh、OpenVINO gaze、Gaze-LLE）、光向（DSINE、法线）、3D（SMPLer-X、HaMeR）、手机端（MediaPipe Tasks、TinyCLIP）。
- 方法：一手来源核查（仓库 LICENSE、模型卡原文、论文出处）；许可证分层（代码/权重/人体参数模型/数据集）；不编造数字（无实测处写“未实测”）。
- 关键一手证据：DSINE LICENSE 为帝国理工自定义非商业许可（verified live 一手读到），DSINE 排除。
- 结论：核心栈（RTMPose/RTMW + MediaPipe + DA3 + Qwen3-VL）许可证干净；3D 模块实验隔离；性能全部待实测。

### 2.2 可行性调研

- 范围：逐组件可行性、许可证复核、性能未知项、Windows/12GB 部署风险。
- 结论：主机抽取可行（RTMPose + DA3 + Qwen3-VL-2B 组合在 12GB 内需 batch=1 冒烟验证）；手机端 MediaPipe Pose 路线通过、性能待真机实测；3D 模块仅实验隔离；DSINE 排除；量化 8B 待实测。

### 2.3 规划稿 v0.2（2026-11-14 02:46）

- 吸收 dot 独立调研与审查纠正（见 §3），形成基线栈 v1 + 升级项 + 3D 实验模块的规划。
- 业主目标、运行环境、卡点清单（B1–B8）、阶段顺序、诚实边界、待拍板事项均已列入。

### 4.3 主要勘误与裁决（Muse 已独立复核标星项）

1. ★ MediaPipe 任务权重 Apache-2.0（模型卡 + issue #6306）。
2. ★ SMPL-X 许可含“非商业艺术项目”条款（单用户、禁分发）+ Body License CC BY 4.0（不含 shape blendshapes）。
3. HaMeR checkpoint 未核实，MANO 另行登记。
4. RTMW 权重缺口未闭合（rtmlib README 提醒 ≠ 许可；issue #3062 答复范围窄）。
5. DSINE 排除同意。
6. ★ 8B GGUF 官方存在，8B 未出局。
7. 虹膜 ≠ 视线：三字段分离（头部朝向 / 眼睛方向 / 画面内落区）。
8. `world_landmarks` 的 z 值 ≠ 相机距离。
9. ★ DA3 换算公式：`metric_depth = focal × net_output / 300`（focal 为像素焦距）。
10. “确定性”≠真实：三层表述（观测证据层—模型估计层—拍摄建议层）。
11. MobileCLIP2 排除（Research Purposes）。
12. 旧合成栈峰值 11,338 MiB 不能证明新栈资源。
13. 阶段顺序：手机最小性能验证提前，LAN 后置。
14. GPU 全局租约：串行占有资源，跨项目统一排队。
15. VLM 白名单字段由 schema 校验器强制，不只靠提示词。

### 4.4 Muse 独立复核结果

Muse 对关键来源独立复核：BlazePose GHUM 3D 模型卡 Apache-2.0 ✅；SMPL-X 许可页条款原文 ✅；官方 Qwen3-VL-8B-Instruct-GGUF Q4_K_M 约 5GB ✅；DA3 公式多处一致来源 ✅；OpenVINO Model Zoo Apache-2.0 ✅；RTMW 缺口确认仍未闭合 ✅。
