> 范围：绝对个人自用、不商用（业主 2026-11-14 01:22 拍板）。本文档只规定路线与需求，不授权执行；代码实施与模型运行须待门禁决定（N2B1P 外部审查硬停仍在）。状态：待组队评审（dot/Grok）与业主拍板。可行性依据：2026-11-14 可行性调研（许可证一手核实 + 发表来源，未实测项均已标注）。

1. 路线总则
• 事实层只用确定性模型，解读层才用 VLM；VLM 不生产姿势坐标。
• 核心栈许可证干净；研究-only 模型只进隔离实验模块、仅本机跑。
• 诚实边界进产品：距离只报范围 + 方法 + 置信度；视线给落区；光向给扇区；2D 角是投影角；遮挡标低置信或缺失。

3. 需求
功能：R1 单张照片出 133 点全身姿势 + 逐点置信度；R2 关节角（标注为投影角）+ 手形摘要；R3 视线落区 + 置信度；R4 距离估计（范围 + 方法 + 置信度）+ 景别；R5 光向扇区 + 光质 + 歧义标注；R6 风格标签（VLM 解读，标明依据）；R7 bundle 导出（带 provenance + 摘要，人工审核后）；R8 App 导入/选择姿势 + 场景推荐；R9 端侧实时 33 点 + 模板匹配 + 引导叠加。

非功能：N1 全离线，照片不离开本机；N2 照片/权重不入库；N3 单张耗时与显存留证据；N4 失败 fail-closed；N5 3D 模块与主流程隔离，可独立开关。


4. 执行步骤（待门禁决定后按序执行，每步业主点头）
• P0 冒烟：20 张校准集 → 133 点 + 深度 + VLM 解读 → 首批真实 bundle，业主抽检。先决：权重许可复核 + 模型下载逐项批准。
• P1 姿势库 v1：Schema 落地 + bundle v2 + 检索去重。
• P2 LAN 跑通：service.py 冒烟 + 手机配对 + 端到端真实分析。
• P3 端侧实时：MediaPipe spike + 模板匹配 + 引导叠加 + 场景推荐，真机验收。
• P4 3D 实验模块（可选并行）：WSL2/Docker 安装 → 真 3D 角度与 2D 对照验收 → 决定是否留用。
