# Pose、分割与 VLM 候选策略

## Pose

候选起点：MMPose 生态中的 RTMPose/RTMW 类模型。采用理由是专业关键点输出、版本化配置和可视化生态。具体模型、人体/手/脸关键点集合、精度与许可必须在 N2 Benchmark 后选择。

硬约束：

- VLM 不生成关键点；
- 关键点有每点置信度；
- 左右语义按人物自身左右，另记录图像左右；
- 镜像检测与镜像策略显式；
- 低可见度不补造坐标；
- 角度由关键点确定性计算。

## 分割

分级策略：

1. 轻量人物分割用于普通候选；
2. 轮廓质量规则判定；
3. 高价值/低质量条目才进入精细分割候选；
4. SAM 2 仅是研究候选，不是默认依赖；
5. 任何 checkpoint 在下载前单独审查。

## VLM

候选起点为适配 12GB 的小型本地视觉语言模型。Qwen3-VL 2B 级可作为研究候选之一，但不预选为生产模型。

Benchmark 重点：

- 可见事实准确率；
- 受限断言违规率；
- JSON Schema 成功率；
- 截图/拼图/多人鲁棒性；
- 中文导演语言质量；
- 相同输入稳定性；
- VRAM/延迟；
- 许可与 exact revision。

## Embedding

延迟到 N6。先确定检索任务和人工相关性集，再选择模型。Embedding 属于敏感派生数据，仍需本地保存和 Git ignore。

## 采用决策

候选评分不是单一总分。任一 P0 安全/许可失败直接淘汰；摄影质量、性能和维护性分别报告。
